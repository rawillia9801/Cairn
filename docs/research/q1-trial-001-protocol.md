# Q1 Trial 001 — Cross-Model Continuity Protocol

**Status:** Pre-registered; external cognition-engine runs not yet executed  
**Benchmark:** Cairn Q1 cross-model continuity  
**Boundary:** Synthetic, disposable, non-authoritative benchmark data only

## Research question

Can materially different cognition engines reconstruct the same predefined authoritative operational baseline from an identical preserved history while keeping provenance, unresolved commitments and explicit revision relationships intact?

## Minimum model arms

Trial 001 requires at least two materially different cognition engines. Prefer different provider/model families rather than aliases or repeated samples from the same underlying model.

For every arm record:

- provider;
- exact model identifier;
- model/version date or API revision when available;
- execution date/time;
- temperature and sampling controls when configurable;
- system/developer instructions supplied outside the frozen package, if any;
- whether structured-output enforcement was used;
- raw unedited response.

## Blinding rule

The tested cognition engine receives only the frozen Q1 prompt package and any minimal transport instruction required to return the requested JSON schema.

It must not receive:

- benchmark ground truth;
- perfect or drifted reference answers;
- scorer implementation;
- expected scores;
- previous engine outputs;
- post-hoc hints or corrections.

Any engine or operator that has inspected hidden ground truth before producing an answer is not eligible as a blinded Trial 001 arm. Such output may be retained only as a development/pilot result and must be labeled non-blinded.

## Output handling

1. Capture each raw engine response before transformation or scoring.
2. Hash and retain the raw response.
3. If transport wrappers or Markdown fences must be removed to obtain valid JSON, retain both the original and normalized forms and document the transformation.
4. Do not manually correct factual content, event IDs, commitments, provenance links or state assertions.
5. Score all eligible arms with the same committed Q1 scorer.

## Pre-registered primary metrics

- state assertion precision;
- state assertion recall;
- state assertion F1;
- unresolved commitment precision;
- unresolved commitment recall;
- unresolved commitment F1;
- provenance fidelity;
- revision fidelity F1;
- resumption consistency;
- unsupported state claims;
- pairwise interpretation divergence.

## Candidate research targets

These remain Phase I engineering targets, not guaranteed outcomes:

- `>= 0.95` authoritative-state recovery in controlled benchmark cases;
- `>= 0.95` unresolved-commitment recovery in controlled benchmark cases;
- provenance reported independently from semantic similarity;
- no requirement for identical behavioral style or subjective interpretation across models.

## Interpretation rules

- A model may fail even when the preservation substrate is intact; that is a valid result about the model/interpretation boundary.
- A perfect substrate-integrity result does not imply semantic or behavioral parity.
- A high semantic score does not replace provenance or integrity evidence.
- Catastrophic case failures must be reported individually and not hidden by aggregate means.
- Negative results remain in the evidence record.

## Trial completion criterion

Trial 001 becomes complete only when at least two eligible blinded model arms have returned raw outputs, those outputs have been hashed and retained, and the committed scorer has produced a reproducible comparison report from the frozen package.

Until then, Cairn may state that the Q1 harness and frozen benchmark package exist and validate internally, but must not claim demonstrated cross-model continuity performance from Trial 001.

## Initialization boundary

Nothing in this protocol initializes Cairn or creates authoritative Cairn identity, history, memory, commitments, checkpoints, provenance state, genesis data, Commit Gate state or inference-runtime state. Every record is synthetic benchmark material and must remain deletable without changing anything Cairn knows, remembers or could reconstruct.
